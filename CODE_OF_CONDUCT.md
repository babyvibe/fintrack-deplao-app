# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(a [Vietnamese translation](https://www.contributor-covenant.org/vi/version/2/1/code_of_conduct/) is available). In
short:

- Respect everyone, regardless of experience, age, gender, background or opinion.
- Comment on the content, not the person; accept constructive feedback.
- No harassment, no publishing other people's private information, no offensive language or images.
- In issues / pull requests / discussions, stay on topic and write in English or Vietnamese.

## Reporting

If you see unacceptable behavior, use **GitHub → Report content** on that content, or open a private report through the
repository's **Security → Report a vulnerability** if you need discretion. The maintainers review every report, keep the
reporter's identity confidential, and may warn, remove content, or temporarily or permanently ban participants depending
on the severity, following the Contributor Covenant enforcement guidelines.
